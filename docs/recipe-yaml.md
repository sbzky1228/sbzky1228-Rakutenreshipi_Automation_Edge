# recipe.yaml の書き方

楽天レシピ・Instagram・TikTok・自分のレシピサイトで共通に使う、レシピの正本ファイルです。
レシピごとのフォルダに、写真と一緒に置きます。

```
チャーシューチャーハン\
├── recipe.yaml
├── main.jpg          ← メインの写真
├── step1.jpg         ← 手順の写真（任意）
└── tiktok.mp4        ← TikTok用の動画（任意）
```

実際の例は [examples/](../examples/) にあります（楽天レシピに投稿済みの4件）。

## 考え方

- **どこにも依存しない情報を書く。** 「約15分」のような楽天レシピの選択肢ではなく、`cook_minutes: 15` のように数値で書きます。投稿先ごとの表現は各投稿ツールが作ります
- **投稿先ごとに変えたい内容だけ `platforms` に書く。** 書かなければ共通の項目が使われます
- **投稿済みかどうかは書かない。** 投稿の状態はデータベースの投稿履歴で管理します
- **フォルダに recipe.yaml があれば、楽天レシピの投稿ツールは recipe.yaml だけを読みます。** recipe.txt が残っていても使われません
  （recipe.yaml に誤りがあるとエラーになり、そのレシピは投稿されません）

## 項目

| 項目 | 必須 | 内容 | 楽天レシピでの使い道 |
|---|---|---|---|
| `schema_version` | ○ | 形式のバージョン。今は `1` | |
| `id` | | 英小文字・数字・ハイフン（例: `chashu-chahan`）。自分のサイトのURLなどに使う | |
| `title` | ○ | レシピのタイトル | レシピタイトル（25文字以内） |
| `dish_name` | | 料理名 | 料理名 |
| `description` | ○ | 紹介文 | レシピコメント（80文字以内） |
| `servings` | ○ | 何人分（整数） | 人数 |
| `cook_minutes` | ○ | 調理時間（分、整数） | 調理時間（「約15分」などに変換） |
| `cost_yen` | | 費用の目安（円、整数） | 費用目安（「500円前後」などに変換） |
| `tags` | | 料理のジャンルなどの語のリスト（例: `[和食, 副菜]`） | |
| `meal` | | `朝食` / `昼食` / `夕食` のリスト | 献立カテゴリ |
| `ingredients` | ○ | 材料のリスト。`name`（必須）・`amount`・`group` | 材料名（20文字以内。`group` は「(A)醤油」のように前に付く）・分量（20文字以内） |
| `steps` | ○ | 作り方のリスト。`text`（必須）・`image` | 作り方（1手順90文字以内。手順の写真の登録は未対応） |
| `story` | ○ | きっかけ | きっかけ（120文字以内） |
| `tips` | | おいしくなるコツ | おいしくなるコツ（120文字以内） |
| `images.main` | ○ | メインの写真（recipe.yaml のフォルダからの相対パス） | 料理写真 |
| `platforms` | | 投稿先ごとの上書き・追加（下記） | |

| 投稿先 | 項目 | 内容 |
|---|---|---|
| `rakuten` | `title` | 楽天レシピだけ別のタイトルにしたいとき（25文字に収めたいときなど） |
| | `categories` | 楽天レシピのカテゴリ名のリスト（書かなければ投稿ツールが自動で選ぶ） |
| `instagram` | `caption` | キャプションの冒頭の文章 |
| | `hashtags` | ハッシュタグのリスト（`#` は付けない） |
| | `images` | 投稿する写真のリスト（1枚目以降） |
| `tiktok` | `video` | 動画ファイル |
| | `caption` | キャプション |
| | `hashtags` | ハッシュタグのリスト（`#` は付けない） |

## 書き方の注意

- 複数行の文章は `|` のあとに改行し、2文字下げて書きます

  ```yaml
  tips: |
    ・塩で水分を抜いた後はしっかり水分を切る
    ・長く漬けるとよりおいしくなります
  ```

  作り方の中で複数行にする場合は、`text` より深く（6文字）下げます

  ```yaml
  steps:
    - text: |
        水分が出たら切って、酢、砂糖に漬けておく
        (足りないときはお好みで追加してください)
  ```

- 値が `yes` / `no` / `true` / `on` などの英単語、`#` や `: `（コロン＋空白）を含む文、`[` で始まる文は `'` で囲みます（例: `story: '#おうちごはん で作りました'`）
- 字下げにはタブではなく空白を使います
- 項目名を書き間違えると「不明な項目があります」と表示されます

## チェック・変換

```bash
# recipe.yaml の内容をチェック（問題があればすべて表示）
python -X utf8 -c "from recipe_poster.recipes.model import load_recipe_yaml; print(load_recipe_yaml('フォルダ/recipe.yaml'))"

# 既存の recipe.txt から recipe.yaml を作る（recipe.txt は残る）
python -X utf8 tools/convert_to_yaml.py                  # 投稿素材のすべて
python -X utf8 tools/convert_to_yaml.py 投稿素材/豚の角煮  # 指定したフォルダだけ
python -X utf8 tools/convert_to_yaml.py --overwrite      # 既にある recipe.yaml も作り直す
```

変換では次のように読み替えます。変換後に内容を確認し、必要なら手で直してください。

- 調理時間に範囲（「15〜20分」）がある場合は長い方、費用に範囲（「800〜1000円」）がある場合は平均
- カテゴリ欄の「朝食」「夕飯」などは `meal`、それ以外は `tags`
- 料理名はフォルダ名
- `id` は作らない（日本語の料理名から自動で決められないため、必要になったら手で付ける）
